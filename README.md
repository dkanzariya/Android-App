# Todo Checkbox List

A simple native Android app where checking a todo item removes it from the list.

## How to run

1. Open this folder in Android Studio.
2. Let Android Studio sync the Gradle project.
3. Run the `app` configuration on an emulator or Android device.

## Behavior

- Type a task and tap **Add** to create a todo.
- Tap the checkbox beside a todo to mark it complete.
- Completed todos are immediately deleted from the list.
